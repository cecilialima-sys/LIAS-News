# Lias News

Portal informativo da Liga de Inteligência Artificial na Saúde (LIAS), com notícias, pesquisas e tendências sobre IA e saúde.

## Domínio de produção

```text
https://liasnews.vercel.app
```

## Desenvolvimento

```bash
pnpm dev
```

Abra `http://localhost:3000` para visualizar o projeto localmente.

## Build

```bash
pnpm build
```

As notícias são mantidas em `lib/noticias.ts` e publicadas em páginas individuais no formato `/noticias/[slug]`.
